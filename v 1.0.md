# Hur man kastar en sten effektivt 
# Målgrupp: icke-stenkastande slutanvändare
# Intstruktioner
1. Hitta en sten som passar bra i handen.
2. Eventuellt stretcha armen innan (beroende på ålder)
3. Provsvinga armen minst 2 till 3 gånger (ej full kraft)
4. Hitta ett mål att kasta stenen på.
5. Sikta in dig på det du vill träffa (Prova att blunda med ett öga ifall det hjälper)
6. Kasta sedan stenen.
